# Сервер A.N.O.D.E

Игровой сервер и реестр серверов в одном файле. Ноль зависимостей — только встроенный
`http` из Node.js, поэтому на бесплатном хостинге он поднимается одним `git push`, без
сборки и без `npm install`.

Лежит здесь, в репозитории игры, по одной причине: **клиент и сервер обязаны понимать
один протокол**, и держать их описание в разных местах — верный способ однажды их
рассорить. Для развёртывания скопируй содержимое этой папки в корень отдельного
репозитория (как ты и хотел) — код от этого не меняется.

## Как поднять на Render

1. Создай пустой репозиторий и положи в его корень `server.js`, `package.json`,
   `render.yaml`, этот `README.md`.
2. В Render: **New → Web Service**, выбери репозиторий.
   - Runtime: **Node**
   - Build Command: оставить пустым
   - Start Command: `node server.js`
   - Health Check Path: `/health`
3. Во вкладке **Environment** выстави параметры (см. ниже).
4. Дождись первого деплоя и скопируй адрес вида `https://имя-сервиса.onrender.com`.
5. В игре: **ПО СЕТИ → Список** → вставь этот адрес → Enter. Список обновится сам.

## Параметры (Environment)

| Переменная | Что задаёт | По умолчанию |
|---|---|---|
| `SERVER_NAME` | имя в списке серверов | `Сервер A.N.O.D.E` |
| `SERVER_DESC` | описание — раскрывается по тапу на карточке | пусто |
| `MAX_PLAYERS` | сколько человек пускать | `16` |
| `GAME_MAP` | какую карту поднять (`kordon`, `chast`, …) | `kordon` |
| `RULES` | правила мира: имена через запятую или число | пусто |
| `PUBLIC_URL` | свой адрес; Render подставляет его сам через `RENDER_EXTERNAL_URL` | из Render |
| `MASTER_URL` | адрес чужого списка, если этот сервер не мастер | пусто |
| `PORT` | порт; Render задаёт сам | `10000` |

### Правила (`RULES`)

| Имя | Что делает |
|---|---|
| `no_bots` | мир без бойцов вовсе — только живые игроки |
| `no_pvp` | пули между игроками не наносят урона |
| `all_friendly` | никто не агрится |
| `all_zombies` | режим смерти: весь мир — зомбированные, сюжетных персонажей нет |
| `no_traders` | торговцев нет, торговля недоступна |
| `army_hold` | армия всё захватила: наёмников нет, посты держат военные |
| `roleplay` | служба по РП — стрельбы между людьми нет, бойцы ходят своими маршрутами |

Примеры:

```
RULES=all_zombies
RULES=army_hold,roleplay
RULES=no_bots,no_pvp
```

`roleplay` сам по себе выключает PvP и вражду — караул, расстреливающий проходящего,
никакой службы не отыграет. Клиент считает так же (`rulesNoPvp` в
`src/Game/Net/GameRules.cpp`), и расходиться этим двум местам нельзя.

## Несколько серверов

Список отдаёт любой сервер. Тот, чей адрес игроки вбили в игре, — мастер; остальным
пропиши `MASTER_URL=https://адрес-мастера.onrender.com`, и они будут раз в минуту
сообщать ему о себе. Сервер, молчавший пять минут, из списка пропадает.

## Протокол

Клиентская часть — `src/Game/Net/Multiplayer.h` и `src/Game/Net/ServerList.h`.

| Ручка | Что делает |
|---|---|
| `GET /health` | проверка живости для хостинга |
| `GET /servers` | список серверов: сам + зарегистрировавшиеся |
| `GET /info` | карточка этого сервера |
| `POST /register` | чужой сервер сообщает о себе |
| `POST /join` | вход: `{name, proto}` → `{ok, id, token, leader, rules, seed, map}` |
| `POST /state` | такт: своё состояние → чужие состояния |
| `POST /leave` | выход |

**Кто чем владеет.** Сервер владеет людьми: кто в партии, где стоит, кто в кого попал,
что сказано в чат, что лежит на земле. Мир вокруг (бойцы) считает один из подключённых —
**ведущий**, тот, кто вошёл раньше всех, — а сервер только передаёт его состояние
остальным. Считать сотню бойцов ещё и на сервере значило бы переписать сюда половину
игры; передавать — значит переслать пару сотен байт за такт.

**Здоровье считает сервер.** Клиент присылает своё, но принимается оно, только если
МЕНЬШЕ известного серверу: иначе достаточно не признавать урон, чтобы стать бессмертным.

## Замечание про бесплатный тариф

Render усыпляет бесплатный инстанс после четверти часа без запросов. Первый вход после
простоя ждёт, пока тот проснётся, — поэтому у запроса списка таймаут двенадцать секунд, а
у входа пятнадцать. Если сервер должен быть доступен всегда, нужен платный тариф или
внешний пинг раз в десять минут.

## Локально

```
cd server
PUBLIC_URL=http://127.0.0.1:8099 PORT=8099 SERVER_NAME="Локальный" node server.js
```

Затем в игре впиши `http://127.0.0.1:8099` в поле «Список». С телефона — адрес компьютера
в той же сети Wi-Fi.
